# מעקב מכולות - איתם 23

מערכת חיזוי וניהול תפעולי (Supply Chain Intelligence) למעקב משלוחים ימי עד הדלת של איתם 23.

## למה המערכת קיימת?
המוצר עונה על השאלה: **"מתי זה אצלי, ומה עלול להשתבש בדרך?"** ולא על "איפה המכולה".

## יכולות מרכזיות
- דשבורד משלוחים עם סטטוס, זמן הגעה משוער חכם וטווחי ביטחון.
- מפה חכמה של מסלול ההפלגה עם מיקום משוער.
- מנוע חיזוי זמן הגעה מתקדם עם תרחיש אופטימי/סביר/פסימי.
- זיהוי חריגות אוטומטי והתראות חכמות.
- מצב סימולציה (What If) להשפעת עיכובים.
- דשבורד ניהולי לתיק משלוחים.

## הרצה מקומית (SQLite ברירת מחדל)
```bash
npm install
npm run prisma:generate
npm run prisma:migrate
npm run seed
npm run dev
```

## הרצה עם Docker (אפליקציה + PostgreSQL)
```bash
docker compose up --build
```

## משתני סביבה
צרו קובץ `.env` לפי הדוגמה:

```
DATABASE_URL="file:./dev.db"
JWT_SECRET="itam23-dev-secret"
REFRESH_CRON="0 */6 * * *"
SMTP_HOST=""
SMTP_PORT=""
SMTP_USER=""
SMTP_PASSWORD=""
WEBHOOK_DEFAULT_URL=""
```

### מעבר ל-PostgreSQL
1. עדכנו את `DATABASE_URL` לכתובת Postgres.
2. החליפו `provider = "sqlite"` ל-`provider = "postgresql"` בקובץ `prisma/schema.prisma`.
3. הריצו `npm run prisma:migrate`.

## לוגיקת זמן הגעה משוער (תמצית)
- טרם יציאה לים: שימוש בממוצע היסטורי או ברירת מחדל (5–10 ימים).
- במהלך הפלגה: שימוש בזמן הגעה רשמי לנמל אם קיים; אחרת טווח רחב (18–28 ימים).
- לאחר הגעה לנמל: 0–3 ימים לפריקה.
- לאחר פריקה: 2–7 ימים לשחרור (5–14 עם עיכוב מכס).
- לאחר זמינות לשחרור: 0–2 ימים הובלה יבשתית.
- לאחר הגעה למחסן: זמן ההגעה הוא היום בפועל.

המנוע מצמצם טווח ככל שיש יותר נתוני היסטוריה ומשקלל עונתיות ו-Transshipment.

## איך להוסיף יעד חדש
1. הוסיפו רשומה לטבלת `destination_profiles` ב-Seed או דרך Prisma.
2. הגדירו זמני הובלה יבשתית, זמני תיאום וחריגות מוכרות.
3. עדכנו את שירות זמן ההגעה להתייחס ליעד החדש לפי הצורך.

## איך להוסיף Carrier Adapter
1. צרו קובץ חדש בתוך `adapters/`.
2. החזירו מבנה אירועים אחיד (`status`, `location`, `eventTime`, `rawText`, `source`).
3. הוסיפו את האדפטר לשירות `refreshService` והעדיפו אותו לפני גיבוי.

## רענון אוטומטי
הרצת משימה יזומה כל 6 שעות:
```bash
npm run refresh
```
ניתן לשנות את תדירות הרענון דרך `REFRESH_CRON`.

## הערות חשובות
- אין שימוש ב-GPS של מכולה. החיזוי מבוסס אירועים לוגיסטיים.
- אם אין API רשמי, ניתן להזין אירועים ידנית או באמצעות Webhook של סוכן שילוח.
